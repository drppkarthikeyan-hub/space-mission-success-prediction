# Space Mission Success Prediction using Machine Learning

This project predicts space mission success using machine learning techniques.

## Dataset Features
- Mission Cost
- Payload Weight
- Fuel Consumption
- Crew Size
- Scientific Yield
- Mission Type
- Launch Vehicle

## Model Used
Random Forest Classifier

## Accuracy
92%

## Project Workflow

1. Uploaded space mission dataset in Google Colab  
2. Cleaned dataset using Pandas  
3. Created Success_Label variable  
4. Split training and testing dataset  
5. Trained Random Forest model  
6. Predicted mission outcomes  
7. Achieved 92% accuracy  
8. Generated visualizations for insights

- Mission success/failure graph
