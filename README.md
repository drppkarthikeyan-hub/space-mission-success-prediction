# Space Mission Success Prediction using Machine Learning

This project predicts space mission success using machine learning techniques.

## Dataset Features
- Mission Cost
- Payload Weight
- Fuel Consumption
- Crew Size
- Scientific Yield
- Mission Type
- Launch Vehicle

## Model Used
Random Forest Classifier

## Accuracy
92%

## Visualizations
- Feature importance
- Correlation heatmap
- Mission success/failure graph

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab
